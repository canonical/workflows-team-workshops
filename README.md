# Workflows Team Workshops

A collection of workshop materials for projects maintained by the Workflows team.

## Overview

This repository contains workshop candidates covering the team's projects, including hands-on guides, demo configurations, and reference materials to help participants get started with each product.

## Repository Structure

Each workshop lives in its own directory:

```
workshops/
├── <project-name>/
│   ├── README.md          # Workshop overview and prerequisites
│   ├── steps/             # Step-by-step instructions
│   └── resources/         # Supporting files (configs, scripts, manifests)
└── ...
```

## Getting Started

1. Browse the available workshops listed below.
2. Open the workshop directory and follow its `README.md` for prerequisites and setup.
3. Work through the steps in order.

## Contributing

To add a new workshop:

1. Create a directory under `root/` named after the project.
2. Include a `README.md` with an overview, prerequisites, and estimated duration.
3. Add step-by-step instructions in a `steps/` subdirectory.
4. Place any supporting files (manifests, configs, scripts) in `resources/`.
5. Update the table above with your workshop entry.
